Fast Realistic Rendering
Physically Based Rendering
PROJECT STATEMENT
In this assignment, we will deal with advanced rendering techniques. The goal is to
get familiar with the elements that are under the hood of Physically Based Rendering
in real-time. To do so, you have to implement a method based on the microfacet
approximation to non-optically flat surfaces using Image Based Lighting techniques.
Particularly, we ask you for:
1.​ [10%] Implementing a basic visualization of the object. This basic visualization
must allow the user to change how the surface is rendered between:
a.​ Material color/texture (include your own) using Phong Shading
b.​ Roughness map (include your own)
c.​ Metalness map (include your own)
2.​ [15%] Implementing an environment reflection shader using a cube texture.
3.​ [30%] Implementing a PBR model using a point light that changes its behavior
depending on the material's roughness and metalness. It should work using:
a.​ global values
b.​ metalness and roughness maps.
4.​ [25%] Implementing an image-based lighting approach based on the use of
cube maps that contain, on one hand, the diffuse irradiance map and, on the
other hand, the cosine weighted specular convolutions. Remember that
material roughness (described on the roughness map) must be a parameter
for the pre-computation and that metalness (described on the metalness map)
must be a parameter for the computation.
IMPORTANT! Both solutions must:
a.​ Approximate the implicit geometry function using the microfacet theory.
b.​ Employ the Schlick’s approximation to Fresnel reflectance.
c.​ Study the differences between linear computation and gamma
correction.
5.​ [20%] You will need to implement some application/code to precompute the
filtered cube maps for (4.b). Before you have this code working, you can find
Cube Maps to use here: http://www.humus.name/index.php?page=Textures
Note: Percentages roughly describe the load of work and the importance of each
part. The grade may not correspond to them.
